## <i class="ph ph-pulse"></i> Active
- **Rearchitecture and Core Maintenance** Modernize the source code that we inherited from K9, tackle the most glaring maintenance and stability issues, and restructure the core architecture for faster and easier development.
- **Notifications & Synchronization** Broken out from the rearchitecture program to prioritize this specific effort, because many of the low ratings are because of this and we are listening to what our community wants. We have documented the current issues and begun introducing initial solutions. This work is closely tied to the rearchitecture effort.
- **Calendar Exploration** We have begun exploring calendar support together with the design team, taking a platform-agnostic approach that will also benefit iOS.

## <i class="ph ph-calendar-blank"></i> Planned
- **Message List Improvements** Users spend most of their time on the message list, waiting for messages to load, scrolling to find messages, and quickly interacting with them through swipe actions. This effort is aimed at improving this primary view and addressing all major concerns. Now planned for 2027.
- **JMAP Support Exploration** Exploring JMAP integration, learning what it means to add a new protocol on Android, and ensuring future proofing against proprietary protocols. Now planned for 2027.
- **Message View Improvements - Phase 2** Modernize the message view to address the most glaring issues like attachment handling, message loading, zoom, remove images, and so on. Making the experience comparable to the competition. Now planned for 2027, as the rearchitecture and core maintenance work will help speed this up.

## <i class="ph ph-rocket-launch"></i> Shipped
- **HTML Signatures** Added support for HTML signatures. This was a community contributor effort, thank you! <div class="date-badge">September 2026</div>
- **CASA Approval** Complete the Cloud Application Security Assessment (CASA) <div class="date-badge">March 2025</div>
- **Thundermail Integration - QR Code Login** Added and prioritized due to the Thundermail release. Implemented one-click OAuth on the first screen and implemented QR code scanning for Thundermail (from web) for easy account setup. <div class="date-badge">June 2026</div>
- **Message View Improvements - Phase 1** We added a message header indicator as well as an attachment button. Now attachments are shown in-line as well as at the bottom of the message. We also improved text rendering and tackled the worst HTML and CSS rendering bug reports, to mitigate the most glaring issues. <div class="date-badge">June 2026</div>
